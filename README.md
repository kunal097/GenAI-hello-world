### Prerequisites

- Python 3.8 or newer
- uv (Python package manager)

---
### Installation

1. **Clone the repository**
    ```
    git clone https://github.com/kunal097/GenAI-hello-world.git
    cd GenAI-hello-world
    ```

2. **Install dependencies**
    ```
    uv pip install -r pyproject.toml
    ```

---

## Usage

1. **Configure your setup**

    - Edit `config.py` to set up any model name which is running locally via ollama.
      

2. **Run the main script**

    ```
    uv run streamlit run main.py
    ```
    Now your server running on http://localhost:8501/
